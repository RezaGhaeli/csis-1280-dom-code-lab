# Trailhead DOM Lab

Ten auto-graded practice activities for **CSIS 1280 Module 9 (The DOM)**, following the
"Bean Jar Challenge: Web Edition" tutorial. Each activity is a small Trailhead Coffee Roasters page:
the HTML and CSS are given, and students write `script.js`.

| # | Activity | Practises |
|---|---|---|
| 1 | Write on the Specials Board | getElementById, textContent, innerHTML, document.title |
| 2 | Count the Menu | querySelector, querySelectorAll, .length |
| 3 | Feature Today's Roast | style (camelCase), classList.add / remove |
| 4 | Show a Result in the Jar | a function with parameters, src, alt |
| 5 | Count the Cups | addEventListener, click, let outside a function |
| 6 | Restock the Beans | .value, Number(), focus() |
| 7 | Check the Brew Temperature | if / else if / else on the page, disabled |
| 8 | The Order Queue | createElement, appendChild, innerHTML = "" |
| 9 | The Shop Clock | new Date(), toLocaleDateString, getHours, setInterval |
| 10 | The Trailhead Dice Board | everything together (final-exam style) |

Each activity also has two multiple-choice questions on the DOM ideas behind it.

**Attempts:** 3 per activity. Each attempt takes 10% off the marks (attempt 1 up to 90%, attempt 2 up to 80%, attempt 3 up to 70%), and the best attempt counts. Set in `js/config.js` (`attempts`).
Progress is saved in the student's browser (localStorage). No server, no accounts.

**To change an activity:** edit `js/activities.js`, run `verify_lab.js` (code-lab-builder skill), then redeploy.
